### Obtaining source

Fabric-ASM's complete source, resources and build script are available at the pinned source tree above, or [as a source archive](https://github.com/Chocohead/Fabric-ASM/archive/39abe596bce4e353594bea207eae43eee181ce9c.tar.gz), under MPL-2.0. Fantasy's complete source and Gradle build files are available at its pinned tree, or [as a source archive](https://github.com/NucleoidMC/fantasy/archive/848aa1d8bd99ccbc5a3c66829023a49298899878.tar.gz), under LGPLv3. Nucleoid also provides the [exact-version sources jar](https://maven.nucleoid.xyz/xyz/nucleoid/fantasy/0.4.11+1.20-rc1/fantasy-0.4.11+1.20-rc1-sources.jar); use the repository for build scripts as well. I haven't modified these libraries.

These links provide source for Fabric-ASM under MPL 2.0 §3.2 and Fantasy under GPLv3 §6(d), which LGPLv3 incorporates. Both the LGPLv3 and GPLv3 texts are included here. This pack adds no restriction on modifying these libraries or reverse engineering to debug those modifications.

**Fantasy and Hexic:** Fantasy's source is available at the links above, but the exact source for this Hexic build isn't public yet. I haven't established a way to replace Fantasy in this build, or supplied the application code needed to rebuild Hexic with a modified Fantasy. Those are the alternatives in LGPLv3 §4(d); linking Fantasy's source alone doesn't resolve this requirement.
